# Dyness CAN BLE — інтеграція для Home Assistant

Читає дані батареї Dyness з ESP32-H2 шлюзу (CAN → BLE GATT) і створює сенсори в Home Assistant.
Дані приходять **пушем** (BLE notify раз на 5 с), без опитування.

## Сенсори

| Сенсор | Одиниці | Примітка |
|---|---|---|
| Напруга, Струм, Потужність | V, A, W | Потужність > 0 — заряд, < 0 — розряд |
| Рівень заряду (SOC), Стан здоров'я (SOH) | % | |
| Температура | °C | |
| Залишкова ємність | Ah | |
| Залишкова енергія | kWh | розраховується як Ah × 51.2 V (як у прошивці) |
| Потужність заряду / розряду | W | |
| Ліміти напруги/струму заряду й розряду | V, A | категорія «діагностика» |
| Назва акумулятора | текст | категорія «діагностика» |

## Встановлення

1. **Прошивка.** Залийте `esphome/dyness-can-ble.yaml` (див. розділ «Важливо про прошивку»).
2. **Інтеграція.** Скопіюйте папку `custom_components/dyness_ble` у `<config>/custom_components/` і перезапустіть Home Assistant
   (або додайте репозиторій в HACS як *Custom repository → Integration*).
3. Пристрій з'явиться в **Налаштування → Пристрої та служби** як знайдений автоматично. Якщо ні — **Додати інтеграцію → Dyness CAN BLE**
   (можна ввести MAC вручну).

Потрібен Bluetooth-адаптер на хості HA або [ESPHome Bluetooth proxy](https://esphome.io/components/bluetooth_proxy/) у зоні дії шлюзу.

## Важливо про прошивку

У вихідному YAML було `value: data: !lambda` для кожної характеристики. ESPHome обчислює таке значення **один раз під час завантаження**
(у цей момент усі сенсори ще NaN), а `ble_server.characteristic.notify` лише надсилає те, що вже лежить у характеристиці.
Тому по BLE завжди приходив би NaN. У `esphome/dyness-can-ble.yaml` це виправлено: `value:` прибрано,
а в `interval` перед кожним `notify` додано `ble_server.characteristic.set_value`. CAN-частина, сенсори та UUID не змінювались.

Формат даних: усі характеристики, крім назви, — `float32` little-endian (4 байти); назва — UTF-8 рядок.

## Обмеження та поради

- Прошивка дозволяє **одне** BLE-з'єднання (`max_connections: 1`). Поки інтеграція активна, вона тримає його.
  Щоб підключитись з телефону (nRF Connect), вимкніть запис інтеграції.
- Якщо використовуєте ESPHome Bluetooth proxy, постійне з'єднання займає один його слот.
- Після обриву зв'язку інтеграція перепідключається сама (затримка 5 → 30 с). Якщо 60 с немає жодного notify, з'єднання перезапускається.
- Сенсори стають `unavailable`, коли BLE-зв'язку немає. Якщо шлюз на зв'язку, але CAN-кадрів немає, останні значення залишаються без змін.
- Для лічильників енергії (Energy dashboard) створіть helper **Інтеграл (Riemann sum)** від сенсорів «Потужність заряду» та «Потужність розряду».
